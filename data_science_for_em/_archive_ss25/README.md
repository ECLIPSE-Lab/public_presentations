# DSEM SS25 archive

This folder holds the Data Science for Electron Microscopy decks from SS25.
The WS 26/27 curriculum replaced them (see
`../docs/superpowers/specs/2026-09-27-dsem-ws2627-curriculum.md`).

The site does not render this folder (`_quarto.yml` excludes it). The decks are
kept as source material: figures, sub-decks and tutorials that the new weeks
reuse or cite.

Relative paths in these decks (for example `../../assets/...` in
`_quarto.yml`) were written for the old location one level higher. Correct
them before you render a deck from here.
